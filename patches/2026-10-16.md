## GHSA-cv23-7vc5-jfh7 · github.com/gomarkdown/markdown

2026-10-16 · Go · **HIGH** 7.5 · Pattern: `NULL_DEREF→CRASH`

### Root cause

The `IsSafeURL` function in `gomarkdown/markdown` did not properly validate the length of the input URL before attempting to slice it. When a short URL (e.g., '.', '..', or empty string) was provided, the code would attempt to slice the URL with a length greater than its actual size, leading to a runtime panic (index out of bounds).

### Impact

An attacker could provide a specially crafted short URL to the `IsSafeURL` function, causing the application to crash due to a panic. This could lead to a denial of service for users of the application.

### Fix summary

The patch adds a length check (`nLink < nPath`) before slicing the URL. If the URL's length is less than the path prefix length, it skips the comparison, preventing the out-of-bounds access and subsequent panic.
