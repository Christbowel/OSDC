The vulnerability stemmed from the application allowing unrestricted file uploads, specifically executable script files, into publicly accessible media directories. Without proper server-side configuration to prevent execution of these files, an attacker could upload a malicious script and then request it directly, leading to arbitrary code execution.

### Impact
